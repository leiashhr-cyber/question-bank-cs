# מאגר שאלות במדעי המחשב + מדעי הנתונים — הוראות העלאה לשרת

הפרויקט הזה הוא הגרסה המלאה של האתר, בנויה כך שתרוץ על תשתית אמיתית וחינמית:
**Supabase** (מסד נתונים, אחסון תמונות, והתחברות מנהל) + **Vercel** (אחסון והרצת האתר עצמו).

כל השלבים למטה נעשים בדפדפן, ללא שום קוד לכתוב בעצמכם.

---

## שלב 1 — יצירת פרויקט ב-Supabase

1. גשי אל [supabase.com](https://supabase.com) ולחצי **Start your project** → הרשמה (חינמית, אין צורך בכרטיס אשראי).
2. צרי פרויקט חדש. תני לו שם (למשל `cs-question-bank`) וסיסמה למסד הנתונים (שמרי אותה — לא תצטרכי אותה שוב בשימוש רגיל).
3. המתיני כדקה עד שהפרויקט מוכן.
4. בתפריט הצד: **SQL Editor** → **New query**. פתחי את הקובץ `supabase-schema.sql` מתוך התיקייה הזו, העתיקי את כל התוכן, הדביקי, ולחצי **Run**.
   - זה יוצר את טבלת הנתונים, את הרשאות הגישה (כולם קוראים, רק את כותבת), ואת מקום האחסון לתמונות.
5. בתפריט הצד: **Authentication** → **Users** → **Add user**. הזיני את המייל שלך וסיסמה שתבחרי. **זה חשבון המנהל שלך לאתר** — אין דף הרשמה ציבורי, רק מי שיש לו את הפרטים האלה יכול להיכנס למצב עריכה.
6. בתפריט הצד: **Project Settings** → **API**. שם תמצאי שני ערכים שתצטרכי בשלב הבא:
   - **Project URL**
   - **anon public key**

---

## שלב 2 — העלאת הקוד ל-GitHub

1. אם אין לך חשבון GitHub — הירשמי בחינם ב-[github.com](https://github.com).
2. צרי מאגר (repository) חדש, ריק.
3. העלי אליו את כל התוכן של התיקייה הזו (יש כמה דרכים — הכי פשוטה: אם GitHub Desktop מותקן אצלך, גררי את התיקייה; אחרת, אפשר להעלות דרך "Upload files" באתר GitHub עצמו לפרויקטים קטנים).

---

## שלב 3 — חיבור ל-Vercel

1. גשי אל [vercel.com](https://vercel.com) → הרשמה (הכי קל: **Continue with GitHub**, כדי שהחשבונות יהיו מחוברים אוטומטית).
2. **Add New** → **Project** → בחרי את המאגר (repository) שיצרת ב-GitHub.
3. Vercel יזהה אוטומטית שזה פרויקט Vite — אין צורך לשנות הגדרות בנייה.
4. **חשוב:** לפני שלוחצים Deploy, פתחי **Environment Variables** והוסיפי שני משתנים (הערכים משלב 1.6):
   - `VITE_SUPABASE_URL` = ה-Project URL
   - `VITE_SUPABASE_ANON_KEY` = ה-anon public key
5. לחצי **Deploy**. אחרי דקה-שתיים יהיה לך אתר חי בכתובת כמו `your-project.vercel.app`.

---

## שימוש שוטף

- **כניסת מנהל**: לחצי על כפתור המנעול, הזיני את המייל והסיסמה שיצרת בשלב 1.5.
- **הוספת/עריכת שאלות ומצגות**: בדיוק כמו בגרסה שכבר הכרת.
- **תמונות**: הדבקה/גרירה של תמונה מעלה אותה ל-Supabase Storage באמת (לא רק זמנית) — היא תישאר שם לצמיתות.
- **גיבוי**: כפתור ה"גיבוי" באתר עדיין עובד באותו אופן (ייצוא/ייבוא JSON).

## דברים שכדאי לדעת

- **הפרויקט של Supabase "נרדם" אחרי שבוע בלי שום פנייה** (המסלול החינמי). אם אף אחד לא נכנס לאתר במשך שבוע (למשל בחופשה), הפרויקט יושהה — לא מאבדים מידע, פשוט צריך ללחוץ "Resume" בדשבורד של Supabase כדי להעיר אותו. אפשר למנוע את זה עם פינג אוטומטי שבועי (חינם, למשל דרך GitHub Actions או UptimeRobot) — תגידי לי אם תרצי שאכין את זה.
- **תכונת "משוב AI"** במצב תרגול לא תעבוד כרגע בשרת החדש (היא דרשה מנגנון מיוחד שהיה זמין רק בתוך Claude). זה מוסבר בקוד (`src/App.jsx`, בתוך `requestFeedback`) — היא נכשלת בעדינות (מציגה הודעת שגיאה) ולא שוברת שום דבר אחר. אפשר לחזור לזה בהמשך אם תרצי, זה ידרוש הגדרת שרת קטן נוסף שמחזיק את מפתח ה-API שלך בבטחה.
- **תמונות שהוסרו משאלה לא נמחקות אוטומטית מהאחסון** (רק ההפניה אליהן מוסרת מהשאלה) — פישוט מכוון כדי לצמצם סיכון בהעברה הראשונה. אם בעתיד ינוצל הרבה מקום אחסון בלי סיבה, אפשר לבנות ניקוי תקופתי.
- המסלול החינמי של Vercel מיועד לשימוש אישי/לא-מסחרי — בדיוק המקרה שלך (אתר כיתה).
